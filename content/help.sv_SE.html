Filter funktion

Verktyg för att filtrera på attribut i tända lager.

 Öppna filter funktionen.

Gör så här:

  • Välj bland de tända lagren i dropdown-listan.
  • Bestäm om filtreringen ska göras på "något" (OR) eller "alla" (AND) av de följande genom att välja i dropdown-listan.
  • Välj vad som ska filtreras på genom att välja i listan för "Attribut".
  • Välj på vilket sätt attributet ska filtreras genom att välja i listan för "Operator".
  • Och slutligen skriv in ett värde.
  • Upprepa om det ska filtreras på flera olika sätt genom att klicka på "Lägg till attribut" och då läggs en till rad att göra val.
  • Klicka på knappen "Filtrera" för att verkställa filtreringen.
  • Klicka på knappen "Rensa" för att ta bort filter på det lager som är valt i "Tända lager".
  • Klicka på knappen "Rensa allt" för att ta bort filter på alla lager.
Under fliken "Avancerad" går det att skriva filter helt själv för de som kan CQL formatet.
Under fliken "Mina filer" finns alla filter som är aktiva och det går att ta bort eller öppna filtren.
Vid "like" filtrering använd % som wildcard tecken.

OBS! Funktionen skiljer på små och stora bokstäver, så det måste stavas exakt som det står för att det ska bli träff.

Jämför kartvyer

Verktyg för att jämföra olika kartvyer. Det går att välja mellan att jämföra sid vid sida eller genom ett kikhål. Lagren som väljs att jämföra emot går att ändra i lagerväljar fönstret, som är flyttbart och går att stänga ner. Den vanliga legenden används för att ändra vilka bakgrunder och lager som ska visas på höger sida (alternativt ovanför kikhålet). Hur mycket av bildytan som ska tas upp av de olika sidorna går att justeras genom att dra i den blå pilknappen i nedre delen av kartan.

Markera i kartan

Verktyg för att markera och välja ut objekt i kartnas lager samt att exportera ut urvalet till extern fil. OBS! Det fungerar inte att markera i alla lager, för att se om det stöds för ett specifikt lager klicka på i lagerväljaren och läs texten längst ner.

 Öppna "Markera i kartan" funktionen.
 Välj objekt i kartan genom att klicka på vart och ett.
 Välj objekt i kartan genom att klicka och dra ut en rektangel över det område du vill ta med.
 Välj objekt i kartan genom att klicka och dra ut en cirkel över det område du vill ta med.
 Välj objekt i kartan genom att klicka flera gånger och ritan en yta över det område du vill ta med. Avsluta med att dubbelklicka eller högerklicka på musen.
 Välj objekt i kartan genom att klicka på objekt och sedan ange ett värde med hur stor buffer runt den geometrin som det ska buffras och välja objekt inom. Tips! Rita först en geometri med ritverktyget där du är intresserad av kunna välja ut objekt med buffer. Stäng ritverktyget och öppna "Markera i kartan"-verktyget och klicka på den ritade geometrin med buffer-knappen.
 Välj objekt i kartan genom att klicka och rita en linje längs det du vill markera.
 Öppna fönstret med export funktionen. Välj vilket format du vill ha. Excel ger alla attributen för valda objekt i ett vanligt kalkyl-ark. GeoJSON skapar en fil med alla attributen och geometrierna som sedan kan användas i andra GIS program som QGIS eller dra in i webbkartan. CSV skapar en kommaseparerad-fil med alla attribut som kan importeras i kalkyl program eller databaser. Det går även att välja att få med geometrierna som ett attribut i ett format som fungerar med text. Är geometrin komplex så kan den bli stor, så behövs den inte klicka ur checkboxen för att inte inkludera.
